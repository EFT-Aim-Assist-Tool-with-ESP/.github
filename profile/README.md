## 📌 About the Tool

**EFT Aim Assist Tool with ESP** offers a balanced combination of automated aiming logic and advanced visual overlays. Built for precision and control, it aligns your aim dynamically toward detected targets while displaying ESP highlights that show positions, outlines, and distances in real time.

---

## ❓ What It Does

- Provides automatic or semi-automatic aim alignment within defined FOV  
- Displays ESP overlays: boxes, skeletons, health bars, and distance meters  
- Supports multiple aim-assist profiles with adjustable speed and sensitivity  
- Highlights visible enemies through custom color filters  
- Allows instant toggling between visual and aim layers via hotkeys
